{% load icons %}{% comment %} The Fleet health card on the Locations page (06-UI-SPEC Page Contracts > S3 > Fleet health card; UI-04, D6-04, polish N13). Parameters: counts (live.fleet_counts of the page's rows: on, off, maintenance, waiting, failing) and total (the number of rows). The page includes it only while it lists at least one location, inside the [data-fleet] wrapper that binds the fleetFilter component. - Header strip: the title "Fleet health" (copy row list.fleet_title) and the description [data-testid=fleet-showing] (list.fleet_showing), polite, with data-total = total. The server renders the unfiltered sentence; fleetFilter rewrites the whole text when a cell is pressed, so the count in it is not a separate mono span. - The proportional bar [data-testid=fleet-bar]: aria-hidden, JS only (rendered hidden). Four segments in this order: on, off, maintenance (hatched), waiting, each with data-status and data-count. fleetFilter sets each segment's flex-grow from data-count and hides the empty ones; the poll refreshes data-count. The segments sit in a row pulled 2 px left inside the clipped track, so the 2 px surface border before each segment shows only between two segments. Delivery failing has no segment: a failing location is also on, off, in maintenance or waiting. - Six cells in a group labelled "Filter the list by status" (list.filter_label, list.cells): [data-testid=fleet-total] All, then [data-testid=fleet-tile] with data-metric on, off, maintenance, waiting and failing. Each cell carries data-count and holds its label (a status LED or the failing triangle, none for All) and its value [data-testid=fleet-count], mono. The value of Off and of Delivery failing takes its tone while the count is above 0, any 0 is subtle; the colour reads the cell's data-count, so a poll that rewrites the count also moves the tone. - Each cell holds a stretched overlay button [data-testid=filter-chip] with data-filter and aria-pressed (All pressed), named by aria-labelledby = the cell's label and value, JS only (rendered hidden), so without JS there are no dead toggles and every location shows. A pressed cell (a shown chip with aria-pressed true) gets the accent fill, border, 2 px top bar and label colour; hovering a cell that is not pressed gives the muted fill and the strong border. The filter never reaches the URL; there is no form. Ids are fixed (one card per page). Every class is spelled out; no class name is built from data. {% endcomment %}
