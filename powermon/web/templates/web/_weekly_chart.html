Context: the detail view's (location, has_history, language_label, chart_trouble). - With stored history: the header action "Open full size" (chart-full-size) and figure[data-testid=weekly-chart] bound to the chartImage component. A link (new tab, noopener) around a 32:25 frame on the muted surface, with a CSS ring spinner behind the image; the image is the location-chart route, 1280 x 1000, loading lazy and decoding async, so the box is reserved and the PNG is only requested once the card scrolls into view. The PNG is shown whole, scaled to the card width and never cropped, filtered or recoloured (in dark mode it stays the light picture inside its border). The caption names the channel's language. The hidden [data-testid=weekly-chart-error] warning is revealed by chartImage when the image fails to load; without JavaScript the browser shows the alt text. - Without stored history (has_history false): the empty state weekly-chart-empty, no image (so no PNG request) and no header action. A waiting location with history, for example after a restore, shows the image. - While the channel's chart fails (an open chart_failing or chart_pin_failed incident), the warning [data-testid=weekly-chart-trouble] with fixed copy heads the body, with or without history; it never names the location (F-04). - The poll never touches this card, so the image is never requested again by it. {% endcomment %}
