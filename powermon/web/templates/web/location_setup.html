Before you start

Use a device that loses power in a blackout: plugged into mains, with no UPS, power bank or battery. A device on backup power keeps reporting and hides the outage.

A heartbeat needs both power and internet at the device. If the router or the provider's network is down, this location is reported OFF too.

The device must send a heartbeat at least every {{ period_s }} s. Power is reported OFF after {{ off_after_s }} s without one.

These do not accept --max-redirect. The heartbeat URL never redirects.

Warning: Do not paste a URL that contains the key into Telegram or any other chat. Chat apps open links to build previews, and every opening counts as a heartbeat: it can mark this location ON while the power is off.

A working heartbeat gets HTTP 200 with the body ok. HTTP 401 means the key is missing or wrong, and nothing is recorded. After the first heartbeat this location shows On; the first heartbeat sends no alert.
