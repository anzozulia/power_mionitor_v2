Parameters: form (the bound, invalid form) and title (the form's Python error, LOCATION_FORM_ERROR or EDIT_FORM_ERROR). The page includes it at the top of the form only when the form has errors, so a valid form never shows one. - An error alert (the Alert component's error tone: the 3 px inset tone bar, the 20 px circle-alert, the visually hidden "Error: " prefix) with role="alert" and tabindex="-1": the errorSummary component focuses it on load, so its links are read first, and the focus shows as the tone bar plus the focus halo and outline. - One jump link per invalid field, in field order: "{label}: {first error}", linking to the control's id (#id_). Labels and errors are the form's Python copy, escaped. - Every class is spelled out, never built from a variable, so the Tailwind scan finds it. {% endcomment %}{% summary_links form as links %}
