Its text is the value exactly: no whitespace inside it, and the break opportunities are empty wbr elements that add no text. For an absolute http or https URL they sit after the scheme separator (found by its position in the value, never by writing the scheme here), and before every path slash: after the host and before /hb. Any other value is shown as it is, with no break point. {% endcomment %}
