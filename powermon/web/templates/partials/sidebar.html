{% load icons timefmt %}{% comment %} The always-dark sidebar of the app layout (06-UI-SPEC Layout Shell > Sidebar; UI-01, UI-03, UI-12). Included once by layouts/app.html, never by the auth or error layouts (R11). Reads sidebar (the lazy context processor of 06-02: rows, counts, current_pk, now, ops_configured; absent for a request without a signed-in user, and then no location group and no ops chip render and no query runs) and request.resolver_match.url_name for the main nav's aria-current (None for a bare request: nothing is current). - Brand row (48 px): zap mark, wordmark, aria-hidden ops tag, link to the list; below lg the drawer close button (JS only, rendered hidden) sits at the right. - Main nav: Locations and Add location, aria-current on the active one. - Locations group: label and count (data-live=sidebar-count), the aria-hidden summary (shell.sb_summary) and its sr sentence (data-live=summary-sr), then one link per location in list order, each one click from its page, aria-current on the location the page is about; "No locations yet" and no summary when there is none. - Each link carries data-location-id, data-status and data-delivery (the poll updates them) and the full name as title; inside it: the LED dot (styled by data-status), the name (one line, ellipsis; the full escaped name stays the text), the sr sentence (data-live=sidebar-sr, shell.sb_sr), the aria-hidden mono cell (data-live=sidebar-cell with data-cell age/off/mnt/wait and data-since, shell.sb_cell, rewritten by the relative component), the failing triangle (data-live=sidebar-fail, rendered hidden while delivery is OK, so the poll can show it) and the rail's Off badge (shown by CSS from data-status, in the rail only). Every per-location live element names its location with data-location-id. - The cells and sentences use sidebar.now (the processor's clock), the same instant as the layout's body data-now, so the server text and the client rewrite agree. - Footer: the "Ops chat off" chip, only while the ops chat is not configured. Layout: below lg a fixed off-canvas drawer (min(240px, 100vw - 56px)), shown while html carries data-drawer=open (set by the sidebar component in admin.js), invisible otherwise so its links are never tabbable while closed; from lg a sticky full-height 240 px column; at xl a 56 px rail while html carries data-rail=collapsed (labels, group text, count and summary visually hidden but still in the DOM, cells hidden, links centred, the triangle and the Off mark as 12 px corner badges). The list scrolls inside the sidebar, never the page. Every class is spelled out: no class name is ever built from data. {% endcomment %}
