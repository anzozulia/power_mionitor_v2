{% load icons %}{% comment %} The Light / Dark / System control in the top bar (06-UI-SPEC Layout Shell > Top bar > Theme control; UI-02, D6-03, R2, R8). Included by layouts/app.html; reads theme (the allowlisted cookie value from the theme context processor) and the CSRF token. A native POST form to the theme route with three submit buttons, so it works without JavaScript (the POST sets the theme cookie and redirects to the fixed list page). aria-pressed is rendered from the cookie, so the pressed button is right on first paint. With JavaScript the theme component (x-data="theme", choose on submit) prevents the submit, writes the same cookie, sets data-theme on html and aria-pressed in place, and never navigates. Each button keeps a 44 px hit box below md and on a coarse pointer and is 28 px from md with a fine pointer; the 28 px visual inside it carries the frame, the pressed fill and the focus ring. Icons sun, moon and monitor; the names are visually hidden text and titles. {% endcomment %}
