{% comment %} The LIVE indicator in the top bar (06-UI-SPEC Layout Shell > Top bar > LIVE indicator; UI-05, UI-11). No parameters. JS only: rendered hidden with data-js-only, revealed by the poll component, which also sets data-live-state (live or paused) and the label's text (data-label: "Live" or "Paused"). The relative component rewrites the age (data-live-age) from the last successful poll; the server renders it as at page render time. Fixed copy only: never a name or a secret (R4). - live: an 8 px round dot in the On colour, pulsing under motion-safe, the label "Live" (uppercased by CSS) and, from md, " · updated {relative}" with the age in mono. - paused: the dot in the warning icon colour without the pulse, the label in the warning text colour, the age hidden. The state styles key off data-live-state through group-data variants, spelled out in full. {% endcomment %}
