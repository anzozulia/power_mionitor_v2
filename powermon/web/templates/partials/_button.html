{% load icons %}{% comment %} Button or button-styled link (06-UI-SPEC Components > Button). Parameters: variant (primary, secondary, ghost, danger, outline-danger), label, href (renders an a element instead of a button), type (default submit), size ("sm" for small controls), testid, sr_suffix (screen-reader-only text after the label), pending_label, name, value, icon (optional: the name of a leading icon, 16 px or 14 px when size is sm, aria-hidden, in --icon on a ghost button; an unknown name raises). Every class is spelled out below, never built from a variable, so the Tailwind scan finds it. Pending (UI-09) is aria-busy plus aria-disabled, set by the submit guard; never the disabled attribute, which would drop the clicked button's name and value from the POST. A button (never a link) is a group and holds a hidden loader-circle spinner before its label: aria-busy hides the leading icon and shows the spinner in its place, at the icon's size and colour, spinning under motion-safe.
